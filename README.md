# 冷眼 ColdEye

台灣 ETF 一手資料與規則化觀點 App：<https://pzwei0105.github.io/coldeye-etf/>

- **只收官方一手來源**：臺灣證券交易所、證券櫃檯買賣中心、臺灣集中保管結算所、美國財政部、中央社、金管會、中央銀行。社群與 KOL 不當資訊來源。
- **觀點由固定規則產生**：同樣的資料，每次得出同樣的結論。每個理由都附官方來源。
- **每個觀點都留紀錄**：回測與上線後的實際戰績，都和「同類 ETF 一直看多／看空」的基準比較（依類別加權，避免類別組成造成假優勢）；某一類 ETF 規則沒有優勢時會自動標示並降低信心。
- **我的部位**：記下交易後，自動算移動平均成本、扣掉手續費與證交稅的損益、已領配息（處理分割與除息資格）、損益兩平價、預估年配息與領息月曆；再依「規則訊號 × 個人紀律（風險屬性、單檔上限、單筆最多虧損、可用現金）」給出加碼、續抱、減碼與股數。持股與交易**只存在手機的瀏覽器**，不會上傳。
- **加碼／減碼訊號也要接受回測**：每種部位訊號之後 20 日的表現，都和同類 ETF 任何一天的表現並列；目前的結果是「挑時機加碼」沒有明顯優勢，「減碼」訊號之後的大跌風險明顯較高。
- **回測從 2020 年起**：包含 2022 年的大跌，也包含後來下市的 ETF，避免只看「活下來的」造成高估。
- **指揮台**：大盤之瞳（全市場 ETF 的規則判讀分布、加權指數、三大法人）、依時段變換的晨報／午報／晚報、今天該注意的事、自選、熱力圖、官方消息；筆電與電視寬螢幕會展開成三欄戰情室。
- **模擬倉**：用虛擬資金在交易時間照「當下」的報價下單（盤中即時價、13:30 以後用收盤價；價格不能自己填、成交後不能改），手續費、證交稅與配息都照真的算，並和「同一天把錢全部買 0050」比較；和真實部位分開存放。
- **ETF 對決**：最多三檔在近一年報酬、波動、回檔、殖利率、受益人數、規則分數六個面向排百分位，附同期走勢。
- **存股時光機**：每月固定日扣款，比較「每月照扣」「只在規則說可以買（可加碼、漲多分批）時才買」「規則說小心時先停扣」三種做法，含分割、配息再投入、手續費與年化報酬（XIRR）；訊號只用扣款日之前就算得出來的。
- **副官（投資小秘書）**：看完資料有想法時說給副官聽——選立場（想買／想賣／觀望／換股）、信心、理由，副官用固定規則逐條檢查（和冷眼規則同向還是唱反調、追高殺低、折溢價、防守線、除息、紀律上限、成交量、規模、情緒用語、大盤大波動），太衝動時建議「冷靜一晚」，隔天開盤前再問一次。
- **決策日記與對答案**：每個想法、以及在冷眼記的今天的交易（含模擬倉），都記下當時的價格與規則觀點，第 20 個交易日自動用含息報酬對答案；你的命中率一律和「同類 ETF 任何一天照同樣方向做」並列，另外拆成跟規則同向／唱反調、有沒有把握、各種理由、冷靜後改主意、和 Claude 討論前後。
- **帶去問 Claude**：把官方資料、規則判讀、你的想法和副官的檢查整理成一段文字，分享或複製給 Claude 討論（只有按下去才離開手機；持股預設只寫比例）。討論完把【冷眼結論】貼回日記，復盤條件裡的價位一鍵變成到價提醒。單檔、整體配置、今日市場、ETF 對決、每週復盤都能打包。
- **資產走勢、部位巡檢、定期定額提醒**：用交易紀錄＋官方收盤重算每天的部位（模擬倉和「全買 0050」並列）；副官巡檢比重、類別、防守線、零碎部位；扣款日當天提醒照紀律扣款。
- **聲光**：開機點火、語音晨報（手機內建的中文語音）、合成音效、震動、分頁掃描、檢查逐條鎖定、蓋章與揭曉；全部可在設定關掉，並尊重「減少動態效果」與手機靜音。
- **看懂模式**：打開後點畫面上任何名詞或數字，就會用白話解釋並套用這檔 ETF 的實際數字。
- **GitHub Actions 定時更新、GitHub Pages 發布**，手機加到主畫面即可使用，不需要開電腦、不需要 API 金鑰。

本工具為個人研究用途的資料整理與規則化分析，不是投顧服務，不保證報酬，投資決策請自行判斷。

## 更新時間（台灣時間，交易日）

| 時間 | 內容 |
|---|---|
| 09:00–13:36，約每 5 分鐘 | 盤中價格、投信預估淨值與折溢價、加權指數、證交所最新消息、中央社 |
| 14:25 | 收盤行情、重算觀點 |
| 15:40 | 三大法人買賣超 |
| 17:50 | 投信公告淨值 |
| 21:55 | 融資融券 |
| 週六 09:20 | 集保受益人數 |

GitHub 的排程忙碌時常常延後半小時以上，所以盤中改成「接力」：每一輪結束前自己排好約 5 分鐘後的下一輪，13:36 後或休市日自動停止；排程只負責開盤前暖身與接力斷掉時的備援。App 狀態列會顯示資料是幾分鐘前的，太舊會變琥珀色，超過兩天沒更新會在首頁警告。

## 架構

```
.github/workflows/coldeye.yml   排程與發布（資料工作與 Pages 發布分開）
pipeline/                       Python 資料引擎（只用 requests）
  sources.py                    各官方來源的抓取與解析
  dispatch.py                   決定這一輪做什麼、盤中接力的時間
  build.py                      每輪流程：回補 → 收盤更新 → 計算 → 輸出（含每檔歷史檔 hist/）
  series.py                     分割與配息還原、指標預先計算
  engine.py                     規則引擎（所有門檻都在這裡）
  narrative.py                  固定句型的白話摘要
  backtest.py                   回測、基準比較、類別優勢
  state.py / gitstate.py        資料存在 state 分支（單一 commit，repo 不會變大）
site/                           手機版 App（純 HTML/CSS/JS 模組，PWA）
  app.js                        外框、開機畫面（點火、語音晨報）、指揮台、部位（含模擬倉、資產走勢）、雷達、情報、戰績、設定
  desk.js                       副官畫面：記下想法＋檢查、冷靜期、決策日記、對答案、帶去問 Claude
  aide.js                       副官純計算：反方檢查、部位巡檢、對答案與基準、戰績統計、打包文字、結論解析
  fx.js                         聲光：合成音效、語音播報、震動、蓋章與揭曉特效
  tools.js                      ETF 對決、存股時光機
  calc.js                       純計算：市場廣度、晨報、時光機、XIRR、資產走勢、對決百分位、熱力圖排版
  viz.js                        圖形：大盤之瞳、熱力圖、六角雷達、折線
  learn.js                      看懂模式的名詞解釋
  sheet.js                      單檔頁：我的部位、冷眼建議、瞄準鏡、試算、交易紀錄、規則分析
  forms.js                      記一筆交易、現金、到價提醒、備份與還原
  core.js                       共用狀態、資料載入、格式與小元件
  pf.js                         部位計算與建議（純函式；所有個人化門檻都在這裡）
control/job.json                推到 main 時要執行的工作：probe / backfill / eod / intraday / deploy
tests/                          本機測試（用官方原始回應，不連網）；pf_test.mjs 測部位計算，calc_test.mjs 測時光機、對決與資產走勢，aide_test.mjs 測副官
```

分支：`main` 放程式；`state` 放累積的官方原始資料與計算結果；`probe-results` 是開發時的來源實測紀錄。
